# Tools


 The MCP server (`golmet mcp`) exposes **15** `gm_*` tools — the same kit the agentic skills drive, straight over the protocol. Transversal mutation rule: ## Two interfaces, one kit  These 15 tools are the **AI path**: inside Opencode (with `golmet mcp` registered), the agents act on the kit **through these tools** - the guards (confirm, dry-run) are enforced on that path. The **human path** is the CLI in the terminal ([commands.md](/docs/reference/commands)) - the same operations, designed for direct management.  MUTATION tools (`gm_update`, `gm_pack_update`, `gm_pack_publish`, `gm_upgrade`) require `confirm=true` — without it they fail with the explicit message ("requires confirm=true; nothing was applied") and `dry_run` lists without applying.  | Tool | Scope | Contract | | --- | --- | --- | | `gm_validate` | workspace | The `golmet validate` payload (errors/warnings §11 + counters + the context: container/product-workspace).
