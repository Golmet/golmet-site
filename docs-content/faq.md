# FAQ

## Is it open source?

MIT licensed. v1.1.1 is published on npm; the source repository opens at the public launch.

## Which agents work with it?

OpenCode, Claude Code, Cursor, Codex, Gemini CLI, Copilot CLI and VS Code Copilot — through the open standards: AGENTS.md, SKILL.md and MCP.

## Does it need a server?

No. The kit is a local native binary; the artifacts live in your own git.

## What is a RN?

A numbered business rule — the versioned agreement between you and your client. Example: `RN-007 — corrida só pode ser aceita pelo motorista dentro de 60 segundos`. Rules are written in plain language, approved by humans, and cited as evidence by the code that implements them.

## How is this different from prompt-only tools?

The truth is not the prompt — it is the versioned state. A deterministic binary validates it; agents only propose. When code and documentation diverge, the kit names the exact rule and the exact file.
